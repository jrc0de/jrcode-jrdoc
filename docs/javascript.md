# JavaScript

## Déclaration de variables

Les variables pointent vers une valeur. Pour assigner une valeur à une variable on utilise le mot clé _let_ et la syntaxe _camel case_ pour le nom de la variable :

```js
let variable = "Bonjour"
let otherVariable = 3
```

Les constantes peuvent être écrites en majuscules :

```js
let PI = 3.14159
```
