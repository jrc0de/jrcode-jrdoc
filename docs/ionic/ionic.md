# Ionic framework

::: tip Ionic Framework
Bibliothèque de composants UI (boutons, listes, menus, etc.) permettant de construire des interfaces mobiles avec les technologies web (HTML, CSS, JS) et compatible avec Vue.js.
:::

## CLI

#### Installer la dernière version du CLI Ionic

```bash
bun add -g @ionic/cli
```

#### Créer un nouveau projet Ionic avec Vue.js

```bash
ionic start [myApp] blank --type vue
```

#### Lancer le serveur de développement

```bash
ionic serve
```

#### Build l'application web

```bash
ionic build
```
